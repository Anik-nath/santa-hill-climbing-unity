# 🎮 Santa Hill Climbing – Unity 2D Game

Santa Hill Climbing is a 2D platform-style game developed using **Unity** and **C#**.  
In this game, the player controls Santa as he drives uphill, collects coins, refuels the vehicle, and avoids obstacles.  
The project was developed as part of the **Computer Graphics & Image Processing Laboratory** course.

---

## 🛠️ Technologies Used

- **Unity Game Engine (2D)**
- **C# Programming Language**
- **Unity Editor**
- **Visual Studio / VS Code**

---

## ✨ Features

- 🚗 Vehicle movement with physics
- 🎥 Smooth camera follow system
- ⛽ Fuel consumption and refilling system
- 🪙 Coin collection & scoring system
- ⏸️ Pause and Resume gameplay
- 🎮 Simple and interactive gameplay mechanics

## 🧩 Scripts Overview

### 📌 Camera Movement
Smoothly follows the player vehicle using interpolation.

### 📌 Vehicle Controller
Handles:
- Car movement
- Wheel torque
- Fuel consumption

### 📌 Fuel System
Refills vehicle fuel when the player collects fuel objects.

### 📌 Pause & Resume
Allows the game to pause and resume using UI buttons.

### 📌 Coin & Score System
Tracks collected coins and updates the score in real time.
